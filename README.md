# Aminjon Ergashev — Portfolio

Готовый одностраничный сайт-портфолио. Для локального просмотра откройте `index.html` в браузере. Сайт не требует сборки и сторонних библиотек.

## Перед публикацией

1. В `index.html` замените Telegram URL и WhatsApp номер на свои реальные контакты.
2. Проверьте адрес `your@email.com` в блоке контактов и обработчике формы.
3. Укажите актуальные цены. Блок отзывов пока содержит заглушки — замените их реальными цитатами клиентов с их разрешения.
4. Чтобы добавить проект, скопируйте один из блоков `.work-small` или `.work-main` в секции `#work`.

В портфолио уже добавлен сайт ресторана [Wok King](https://ameenjon.github.io/wok-king/). Его исходники опубликованы в [репозитории Wok King](https://github.com/ameenjon/wok-king).

## Публикация на GitHub Pages

Загрузите `index.html`, `portrait.png` и этот README в корень репозитория на GitHub. В настройках репозитория откройте **Pages**, выберите публикацию из ветки `main`, папки `/ (root)`, и сохраните. Через несколько минут страница станет доступна по адресу GitHub Pages.

Цвета находятся в начале CSS в переменных `:root`. Тексты интерфейса RU/EN/UZ/HU собраны в объекте `translations` внизу файла.
